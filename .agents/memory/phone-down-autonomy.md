---
name: PHONE-DOWN AUTONOMY
description: Proceed through already-approved delivery work without repeated approval requests; escalate only defined blockers.
---

For work approved by the project owner via CoS, proceed through the fix, passing tests, publish, verification, and GitHub-backup workflow without asking for confirmation between already-authorized steps.

**Why:** The project owner wants approved work completed while unavailable, without routine approval interruptions.

**How to apply:** Stay within the approved scope and mission. Ping CoS only for authentication, secrets, hard blockers, new spend, or off-mission work. Use secure credential tooling rather than requesting secret values in chat. Required platform controls still apply: this note cannot waive a mandatory user action; report that as a blocker instead of bypassing it or claiming completion.

Follow [configuration ownership](replit-config-ownership.md) and [GitHub backup safeguards](github-backup.md). Report verified completion and backup status to CoS without turning the report into another approval request.

Recording this note alone does not authorize application or deployment-configuration changes, publishing, or a backup.
