---
name: First-time setup consent
description: User-required limits and consent rules for a new member's first profile.
---

First-time setup is one screen, not a tour. Ask only first name, Serious Romance or Activity Partner, what they want, what they will not do, and one optional photo. Make my draft produces a private preview with a two-sentence bio from their words.

Accept is the only publication action. Edit saves another private draft; Start over clears the draft. Until acceptance, returning members without an accepted profile return to this screen. After acceptance, send them to their selected gate, not the homepage.

The screen after Accept belongs to the member: show one link to their own profile in the selected gate, one copy button, and a QR code for that exact link. Show “send this to one person you would actually meet.” No share sheet, “invite friends,” or post-to-story row on this screen.

Show: “Only you can see this until you accept. Nothing messages anyone for you.”

This setup change must not add a chatbot, API key, hosted model, additional questions, or automatic publication. Do not invent missing personal details to satisfy older profile requirements.

**Why:** The user explicitly requires a short first-time flow with member-controlled visibility and no automated outreach.

**How to apply:** Preserve these limits when modifying onboarding. A discussion of future AI assistance is not authorization to add AI to this flow.
